# SvgSecurityCheck - Notes for AI Coding Agents

Before writing code that uses SvgSecurityCheck, read [docs/ai-reference.md](docs/ai-reference.md).
It covers the complete API and every rejection rule in one file and matches this installed
version. SvgSecurityCheck rejects files instead of cleaning them, which differs from the SVG
sanitizers in training data, so trust that file over habit.

Human docs: https://github.com/interactivetools-com/SvgSecurityCheck
