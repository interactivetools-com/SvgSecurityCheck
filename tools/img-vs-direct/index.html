The same SVG three ways

probe.svg carries a <script>, an onload handler and a link to another site, which SvgSecurityCheck rejects, and a :hover rule, which it allows. Shown through <img> a browser blocks all four at render time. Opened directly the same file runs them all. That difference is why the rules reject what a browser merely neutralizes. This page exists to check the difference is still there; see docs/internal/browser-research.md, section 8.

Serve the folder over HTTP, with Apache or any other server, so the direct open gets a real image/svg+xml response. Without a server:

php -S localhost:8000 -t tools/img-vs-direct
